# VegVision

Фронтенд-проект на `Next.js` для интерфейса системы мониторинга состояния растений.

## Стек

- `Next.js` (`App Router`)
- `React`
- `TypeScript`
- `SCSS modules`
- `pnpm`
- архитектура `FSD`

## Установка зависимостей

```bash
pnpm install
```

## Запуск в режиме разработки

```bash
pnpm dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Основные команды

```bash
pnpm dev
pnpm build
pnpm start
pnpm lint
```

## Структура проекта

- `app/` — роутинг и `layout/page`-файлы
- `shared/` — общий UI и утилиты
- `features/` — пользовательские сценарии
- `widgets/` — крупные блоки интерфейса
- `entities/` — предметные сущности
- `docs/FSD.md` — описание текущей FSD-структуры

## Примечания

- Для управления зависимостями используется только `pnpm`
- `package-lock.json` в проекте не используется
- При добавлении новых модулей лучше придерживаться текущей FSD-структуры
