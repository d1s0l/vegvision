# Обсудить с командой добавление функций

- Двухфакторная авторизация
    Подтверждение входа через почту или приложение-аутентификатор
           
- Управление сессиями
    Список активных устройств и кнопка завершения лишних входов

- Настройки команды
    Приглашения коллег, роли доступа и права на просмотр аналитики
